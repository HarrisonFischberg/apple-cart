# Data inventory

Planned (blueprint 2026-11-14). Everything stays on the Mac unless a row says otherwise.

| Data | Purpose | Collection point | Recipient / storage | Retention | Deletion |
| --- | --- | --- | --- | --- | --- |
| Tool settings and battery policy | remember choices | Settings, panel | UserDefaults (local) | until changed | Delete all app data; removing the app |
| Battery samples (percent, temperature, watts, cycles) | 24 h history graphs | IOKit readings | Application Support store (local) | 24 hours rolling | automatic; Delete all app data |
| Schedule tasks and run history | battery schedule | Settings > Battery | local store | tasks until deleted; runs 30 days | delete task; Delete all app data |
| Clipboard items (text, links, images, colors) | clipboard history | system pasteboard, only while the tool is on | local store; images as local files | 7 days default (owner-set), pinned kept | per item, clear all, turning the tool off offers to clear, Delete all app data |
| Sensitive pasteboard items (concealed, transient, auto-generated, excluded apps) | none | — | never stored | — | — |
| App names and leftover file paths | uninstaller and cleaner preview | file system scan on request | memory only during the scan | not kept | — |
| Update check request | app updates (Sparkle) | automatic or manual check | GitHub Releases receives IP address and user agent with app version | per GitHub's policies | turn off automatic checks |
| Debug logs | support | user taps Send Debug Logs | Mail draft the user reviews and sends to the support address | per the user's mailbox and support inbox | user-controlled |
| Hardware state applied by the root helper | charge control, fan speed and the MagSafe light (Indicate charge limit) | XPC commands from the signed app only (code-signing requirement: bundle ID + team ID) | root helper memory only (adapter cut, fan mode, forced light colour and the value macOS last set, lease timers); no files, no network | at most the 90 s lease, renewed every 30 s while a limit is held or a colour is forced | lease expiry, signal, app disconnect, sleep and helper start all put the charger back on and stop forcing the fans and light; tool off, quit, Delete all app data and Remove call resetAll, resetFan and resetLED; turning Indicate charge limit off calls resetLED |
| Charge control settings (limit, below-80 toggle, Top Up, sailing difference, automatic discharge, heat max in Celsius) | charge limit | Settings > Battery, panel | UserDefaults (local); the helper only ever receives "charger on" or "charger off for N seconds" | until changed | Delete all app data |
| System readings: CPU/GPU temperatures (AppleSMC Tp*/Te*/Tg* float keys, read-only), CPU ticks, GPU load (IOAccelerator PerformanceStatistics), per-process CPU time and memory footprint (proc_pid_rusage), per-process GPU time (IOAccelerator user clients AppUsage), memory and swap counters, memory pressure level, boot time | System tool: temperatures, usage bars, 2-minute graphs, apps using CPU, GPU and memory, uptime | read every 2 s only while the System view is open; process names come from executable paths, never from app contents | app memory only | about 2 minutes of history, dropped when the view closes | automatic |
| Battery sensors: battery temperature (AppleSMC TB0T/TB1T/TB2T float keys, read-only) and the MagSafe light colour (AppleSMC ACLC ui8 key; 3 = green, 4 = orange, else unknown) | Battery Details temperature and MagSafe light rows, Settings heat row and light row, heat protection pauses, Get Battery Temperature shortcut | read with each battery sample (every 2-20 s) only while something on the Battery tool samples; unprivileged. The app never writes them; the root helper writes ACLC (3 or 4 only) only while Indicate charge limit is on and the light should be forced | app memory, plus the temperature inside the battery samples above | same as battery samples | automatic |
| Fan readings: fan count, actual, minimum and maximum rpm (AppleSMC FNum ui8, F*Ac/F*Mn/F*Mx float keys, read-only, unprivileged) | Fan speed panel: live speed per fan, the 0-100% scale | read every 5 s only while the Fan speed tool is on | app memory only | not kept | automatic |
| Fan control (root helper writes: F*md 0/1, F*Tg target rpm float, and Ftst 0/1 only on Macs that have it; this Mac does not) | Fan speed tool: Manual | XPC setFan(rpm, lease) from the signed app, only after Apply and only while the tool is on and a temperature is known | root helper memory only (target, lease timer); no files, no network | at most the 90 s lease, renewed every 30 s | lease expiry, signal, app disconnect, sleep and helper start all hand the fans back to macOS (mode 0); tool off, quit, Delete all app data and Remove call resetFan |
| Fan settings (applied mode, manual percent, Resume) | Fan speed tool | panel | UserDefaults (local, keys fan.*) | until changed | Delete all app data |
| macOS and Homebrew update lists (`softwareupdate --list`, `brew outdated`) | Updates tool, only when the user presses Check now | macOS contacts Apple and Homebrew may contact its own servers, exactly as when run by hand; the app sends nothing itself | app memory only | not kept | automatic |

No analytics, crash reporting, advertising or AI providers.

Root helper (T009, 2026-11-15): `AppleCartHelper`, a launchd daemon embedded in the app and registered with `SMAppService.daemon`. Local only: it talks to the Apple Cart app over XPC and to the Mac's SMC, never to the network, and it stores nothing. New data flow, no new vendor.
